# Placement Atlas 2027

A free list of internships, insight weeks and summer schools for university students of any degree, year and nationality.

Live site: https://placement-atlas.netlify.app

- `index.html` — the whole site (listings live in the `ROWS` array in the page script; `LAST_CHECKED` holds the last-checked date)
- `404.html` — page-not-found page
- `robots.txt` — lets search engines index the site

Netlify publishes this repository automatically whenever `main` changes.
